External services

🔑

OTP / phone & email verification

Stubbed
Where
Registration wizards — features/register/widgets/otp.jsx
Today
"Send OTP" shows a toast (Demo: use 123456); verification passes only if the user types 123456. Pure client-side theatre — no code is generated, sent, or checked server-side.
Missing
An SMS provider (e.g. Twilio / MSG91 / AWS SNS) and email OTP delivery, a backend endpoint to generate + store + rate-limit + expire codes, and a verified-status flag persisted on the user.
Impact
High — verification is trivially bypassed; phone/email are effectively unverified.
✉️

Email service

Missing
Where
Registration, password reset, notifications, quotes
Today
No mail dependency in the backend (no spring-boot-starter-mail), no SMTP config, no templates. No welcome, verification, receipt, or notification emails are ever sent.
Missing
An SMTP/API provider (SendGrid / SES / Postmark), mail config per profile, and transactional templates. Frontend "Email + App" notification preferences point at nothing.
Impact
High — blocks verification, password reset, and all transactional comms.
🗺️

Maps / geolocation

Faked
Where
Browse billboards map view; owner/advertiser dashboards
Today
No mapping library is installed (no Leaflet, Mapbox, Google Maps, MapLibre — confirmed in package.json). The "map" is a decorative background with pins positioned by hard-coded mapX/mapY percentages in browseData.js. Listings carry no real latitude/longitude.
Missing
A map SDK + API key, real geocoordinates on listings, geocoding of addresses, and radius/location search on the backend.
Impact
Medium — location is a core discovery axis for OOH inventory.
📎

File uploads & storage

Stubbed
Where
Logo upload, KYC/verification docs, campaign creatives, portfolios — features/register/widgets/uploads.jsx
Today
Every upload zone reads the file locally and shows a success toast. Nothing is transmitted; there is no multipart endpoint and no storage backend.
Missing
Object storage (S3 / GCS / Azure Blob), a multipart upload endpoint, server-side type/size validation and virus scanning, and persisted file references on the profile entities.
Impact
Medium — KYC/verification cannot actually complete.
💳

Payments / booking

Missing
Where
Browse "Book", dashboard quotes & proposals, packages
Today
Prices and package tiers are display-only. No payment gateway (Razorpay / Stripe), no order/booking entity, no checkout flow.
Missing
A payment provider integration, booking/order domain + endpoints, invoicing, and payout handling for owners.
Impact
Medium — the marketplace can't transact yet (may be intentionally out of current phase).

Data & backend endpoints

🔌

Read/query APIs for dashboards & browse

Missing
Where
All three dashboards, Browse, Browse Agencies
Today
Backend exposes only AuthController, RegistrationController, and PingController. Entities/repositories for listings, campaigns and portfolios exist but no controller serves them, so every screen falls back to data.jsx imports.
Missing
GET endpoints for listings (with filter/sort/pagination), agencies, quotes, notifications, and dashboard aggregates — then a fetch layer on the frontend to replace the static imports.
Impact
High — this is the blocker behind the whole Dummy Data report.
🔒

Password reset ("Forgot password?")

Missing
Where
Login modal — features/auth/AuthModal/AuthModal.jsx
Today
The link is href="#" with e.preventDefault() — a dead no-op. No reset endpoint exists.
Missing
A token-based reset flow (request → emailed link → set new password), which also depends on the email service above.
Impact
Medium — locked-out users have no recovery path.
🔎

Search & filtering

Client-only
Where
Browse, Browse Agencies, landing search bar
Today
Filters/sorts run in the browser over the 12 static listings. There is no server-side search, no pagination, and the results won't scale past the hard-coded array.
Missing
Backend query params (city/type/price/footfall/tags), pagination, and optionally full-text search.
Impact
Medium
